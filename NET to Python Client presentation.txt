Project Title:
 Migration from .NET Modular Monolith to Python (FastAPI)
________________


1. Project Overview
Objective:
 Convert the existing .NET-based eShop Modular Monolith to Python using FastAPI, while preserving its architecture, structure, naming conventions, and business logic.
Goals:
* Maintain 1:1 parity with the .NET codebase

* Deliver a modular, testable, scalable FastAPI backend

* Ensure each milestone is client-runnable with Docker

________________


2. Current vs Proposed Architecture
Current (.NET) Architecture:
   * Modules: Identity, Catalog, Ordering

   * Layers: API, Application, Domain, Infrastructure

   * Patterns: DDD, CQRS, Mediator, Outbox[a]

Proposed (Python) Architecture:
      * Maintain modular structure: modules/identity, modules/catalog, modules/ordering

      * Preserve layered design: api/, application/, domain/, infrastructure/

      * Replicate patterns: CQRS, DI, Mediator, DDD, Outbox, Object Mapping

________________
